`mdwn` is a fast and light Markdown viewer written entirely in C.

It supports different Markdown flavors:

- **Github**, inspired from the official [Primer CSS Markdown sources](https://github.com/primer/css/tree/5e66b1a87905c1ce9f3268676a91e1002d2dcb5e/src/markdown) and [Primer Primitives](https://github.com/primer/primitives/tree/30cb00c65d789d6ad4850f8a4fd172276e143226)
